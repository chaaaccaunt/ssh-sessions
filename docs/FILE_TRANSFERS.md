# Передача файлов

`upload` и `download` запускают отдельный процесс `scp` и отдельное SSH-соединение. Каталоги
передаются только с явным `--recursive`; прогресс в терминале выводится самим `scp`.

Неуспешный, отменённый или завершённый по timeout вызов API возвращает
`potentiallyPartial: true`: локальный или удалённый файл мог быть создан лишь частично.
Замена удалённого файла через `scp` не является атомарной.

`files` запускает стандартный интерактивный `sftp`. Метод `executeFileBatch` принимает только
типизированные операции, экранирует пути и запрещает переводы строк. Batch прекращается при
первой обязательной ошибке, но уже выполненные операции не откатываются; при сбое результат
также содержит `potentiallyPartial: true`.
