# Выполнение удалённых команд

`exec` передаёт удалённую команду программе `ssh` одним аргументом и никогда не
запускает локальную оболочку. Строку затем интерпретирует удалённая shell, поэтому
правила quoting зависят от неё: POSIX shell, PowerShell и `cmd.exe` несовместимы.

В CLI всю удалённую команду нужно передавать одним, корректно заключённым в кавычки
аргументом после `--`:

```text
ssh-session exec production -- "printf '%s\\n' 'hello world'"
```

По умолчанию PTY не выделяется (`-T`); `--tty` явно запрашивает его (`-tt`). API
возвращает исходный exit code. Код `255` может принадлежать как `ssh`, так и самой
удалённой команде, а после сетевого обрыва нельзя достоверно определить, продолжает
ли удалённый процесс работу.
